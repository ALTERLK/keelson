# Skill Instructions

- Present the PR changes as a concise bulleted list.
- Keep each bullet point brief, clear, and focused on key modifications.
- Avoid large blocks of text or verbose explanations.

## Creation Evidence

- 以后总结 PR 改动都用要点列表的形式，保持简洁，不要写大段文字。
